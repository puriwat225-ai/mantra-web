📋 ขั้นตอนเร็ว:

1️⃣  เข้า https://github.com → Sign up (ถ้ายังไม่มี account)

2️⃣  สร้าง Repository ใหม่:
    - ปุ่ม "+" มุมขวา → New repository
    - Name: mantra-web
    - Public ✓
    - Create repository

3️⃣  Upload ไฟล์:
    - Repository page → "uploading an existing file"
    - ลาก folder mantra-web ทั้งหมดลงไป
    - Commit

4️⃣  Enable GitHub Pages:
    - Repository → Settings (มุมขวา)
    - Left menu → Pages
    - Source: Deploy from a branch
    - Branch: main → / (root) → Save
    - รอ 1-2 นาที

5️⃣  ได้ URL แล้ว!
    https://yourusername.github.io/mantra-web

6️⃣  สร้าง QR Code:
    - https://qr-server.com/api/
    - Paste URL ของคุณ
    - Download → Print
